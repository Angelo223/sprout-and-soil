# Sprout & Soil - Game Concept

## Vision

**Sprout & Soil** is a cozy mobile garden game about experimentation, discovery, and gentle learning.

Players build small garden beds, plant crops, care for them, and slowly discover which plants support each other and which combinations create problems.

The game should feel colorful, calm, rewarding, and friendly. Learning should happen through play, not through lectures.

## Core design pillars

### 1. Cozy first

The game should feel relaxing and warm. Failure should never feel harsh or punishing.

### 2. Discovery over instruction

Plant relationships are hidden at first. Players learn through observation and experience.

### 3. Every problem teaches something

When a harvest fails, gets damaged, or is affected by pests, the player receives a short explanation of what happened and why.

### 4. Fair monetization

The game should be free-to-play, but purchases must not create direct gameplay advantages. Optional purchases should focus on cosmetics, decoration, themes, companions, and personal expression.

## Main gameplay loop

1. Choose an empty garden tile or bed.
2. Plant a seed.
3. Water and care for the plant.
4. Observe growth, health, pests, and neighboring effects.
5. Harvest the result.
6. Unlock diary entries, cosmetic rewards, or new goals.
7. Improve the garden layout based on what was learned.

## Learning loop

1. Player tries a plant combination.
2. The game simulates the result.
3. The player sees a positive, neutral, or negative outcome.
4. The garden diary records the discovery.
5. The game explains the reason in simple language.

## Example plant relationships

These examples are placeholders and should be validated before final release.

- Carrot + Onion: good relationship
- Tomato + Basil: good relationship
- Tomato + Potato: risky relationship
- Corn + Bean + Squash: special combination

## MVP scope

The first playable version should be intentionally small:

- 3x3 garden grid
- 8 initial plants
- Basic planting, watering, growth, and harvest
- Hidden compatibility rules
- Pest or damage event for bad combinations
- Garden diary for discovered relationships
- Simple mobile-friendly UI

## Monetization direction

Allowed:

- Decorative garden themes
- Cosmetic bed styles
- Companion animals
- Special animations
- Optional premium diary visuals or deeper real-world plant notes

Avoid:

- Paying to skip core learning
- Paying for stronger harvests
- Energy systems
- Forced ads
- Hard progress blockers
